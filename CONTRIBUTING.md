# Contributing to gcli

You are very welcome to submit patches, fixes, bug reports and/or feature requests.
Please do not hesitate to contact us!

Please submit them to our mailing list at:

	~herrhotzenplotz/gcli-devel@lists.sr.ht

## General discussions

General discussion happens on IRC (even if you just want to say hello :-) ):

	#gcli on Libera.Chat

Never used IRC before? Go [here](https://libera.chat/guides/basics).

Or alternatively use our users mailing list:

	~herrhotzenplotz/gcli-users@lists.sr.ht

## Bug reports / Feature requests

You can post bug reports or feature requests (preference in descending order) here:

- `~herrhotzenplotz/gcli-users@lists.sr.ht`
- `https://todo.sr.ht/~herrhotzenplotz/gcli`
- `https://gitlab.com/herrhotzenplotz/gcli/issues`
- `https://github.com/herrhotzenplotz/gcli/issues`

## Guidelines

You can find general information about working on the codebase in [HACKING.md](/HACKING.md).

Before just implementing a new feature please discuss!

### AI / LLMs

- You must not submit AI/LLM generated patches. Patches generated in such a way will not be accepted.
- You must not post AI/LLM generated content to issue trackers or mailing list, we prefer human interactions.

## Legal

By submitting source code for inclusion in gcli, you attest:

1. You only submit code that you are legally entitled to submit
2. Submitted code shall be covered by BSD license as found in LICENSE
3. Submitted code is not computer-generated

(Note: This stance is taken, in adjusted form, from [9front](https://git.9front.org/plan9front/9front/2e21c09e8cdbca26aa3b069699239467e1fabc40/lib/legal/contributing/f.html))
